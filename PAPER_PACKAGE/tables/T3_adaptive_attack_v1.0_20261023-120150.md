3. **并集注**：Ours 的 n = 360 = 3 seed 合池（非「三 seed 并集」口径；自适应链按 (样本, seed) 配对计数）。
4. **B6 边界注**：B6 **未参与自适应攻击实验**（无 seed／run 轴、非本项目防护臂）⇒ 本表无 B6 行；凡他处引用自适应结论不得外推至 B6。
